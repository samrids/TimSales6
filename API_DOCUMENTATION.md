# API Documentation - Grist Integration
## TimSales6 Agricultural Sales Management System

### Overview

This document provides detailed information about the Grist API integration used in TimSales6 application. The app uses Grist's REST API to perform CRUD operations on agricultural sales data.

## Timestamp Handling

### Problem
Grist returns timestamps in different formats:
- Unix timestamp: `1726483200.123456`
- ISO string: `2025-09-16T10:30:00+07:00`
- Simple string: `2025-09-16 10:30:00`

### Solution
Custom TypeAdapter that handles all formats:

```kotlin
class FlexibleTimestampAdapter : TypeAdapter<String?>() {
    override fun read(reader: JsonReader?): String? {
        return when (reader?.peek()) {
            JsonToken.NUMBER -> {
                val timestamp = reader.nextDouble().toLong()
                val date = Date(timestamp * 1000)
                SimpleDateFormat("yyyy-MM-dd HH:mm:ss", Locale.getDefault()).format(date)
            }
            JsonToken.STRING -> reader.nextString()
            JsonToken.NULL -> {
                reader.nextNull()
                null
            }
            else -> reader?.nextString()
        }
    }
    
    override fun write(writer: JsonWriter?, value: String?) {
        if (value == null) {
            writer?.nullValue()
        } else {
            writer?.value(value)
        }
    }
}
```

## Error Handling

### Common HTTP Status Codes

| Code | Meaning | Possible Causes |
|------|---------|-----------------|
| 200  | OK | Successful operation |
| 400  | Bad Request | Invalid request body or parameters |
| 401  | Unauthorized | Invalid or missing API key |
| 403  | Forbidden | API key doesn't have required permissions |
| 404  | Not Found | Document, table, or record doesn't exist |
| 500  | Internal Server Error | Grist server error |

### Error Response Format
```json
{
  "error": "Detailed error message",
  "details": {
    "code": "ERROR_CODE",
    "message": "Additional context"
  }
}
```

### Implementation
```kotlin
suspend fun handleApiCall(): ApiResult<SalesRecord> {
    return try {
        val response = apiService.getSalesRecord(id)
        if (response.isSuccessful) {
            ApiResult.Success(response.body()!!)
        } else {
            val errorBody = response.errorBody()?.string()
            ApiResult.Error(Exception("API Error: ${response.code()} - $errorBody"))
        }
    } catch (e: UnknownHostException) {
        ApiResult.Error(Exception("Network Error: Unable to connect to server"))
    } catch (e: Exception) {
        ApiResult.Error(e)
    }
}
```

## Rate Limiting

### Grist API Limits
- **Free Plan**: 5,000 API calls per month
- **Pro Plan**: 50,000 API calls per month
- **Business Plan**: 500,000 API calls per month

### Best Practices
1. **Batch Operations**: Use batch create/update when possible
2. **Caching**: Cache frequently accessed data locally
3. **Debouncing**: Avoid rapid successive API calls
4. **Error Retry**: Implement exponential backoff for failed requests

```kotlin
class ApiRateLimiter {
    private val lastCallTime = AtomicLong(0)
    private val minInterval = 1000L // 1 second between calls
    
    suspend fun throttle() {
        val now = System.currentTimeMillis()
        val timeSinceLastCall = now - lastCallTime.get()
        
        if (timeSinceLastCall < minInterval) {
            delay(minInterval - timeSinceLastCall)
        }
        
        lastCallTime.set(System.currentTimeMillis())
    }
}
```

### Network Optimization

### Caching Strategy
```kotlin

val cache = Cache(context.cacheDir, cacheSize.toLong())

    .cache(cache)
    .addInterceptor { chain ->
        val request = chain.request().newBuilder()

            .build()
        chain.proceed(request)
    }
    .build()
```

### Usage Metrics
```kotlin
class ApiUsageTracker {
    private val callCount = AtomicInteger(0)
    private val totalDuration = AtomicLong(0)
    
    fun recordCall(duration: Long) {
        callCount.incrementAndGet()
        totalDuration.addAndGet(duration)
    }
    
    fun getAverageResponseTime(): Double {
        val calls = callCount.get()
        return if (calls > 0) {
            totalDuration.get().toDouble() / calls
        } else 0.0
    }
}
```

## Troubleshooting Guide

### Common Issues and Solutions

#### 1. Authentication Failures
**Problem**: 401 Unauthorized responses
**Solution**: 
- Verify API key is correct and active
- Check Bearer token format
- Ensure key has required permissions

#### 2. Network Timeouts
**Problem**: Requests timing out
**Solution**:
- Increase timeout values
- Check internet connectivity
- Verify Grist service status

#### 3. Data Parsing Errors
**Problem**: JSON parsing failures
**Solution**:
- Verify data model matches API response
- Check timestamp format handling
- Enable detailed logging

#### 4. Rate Limiting
**Problem**: Too many requests error
**Solution**:
- Implement request throttling
- Use batch operations
- Upgrade Grist plan
